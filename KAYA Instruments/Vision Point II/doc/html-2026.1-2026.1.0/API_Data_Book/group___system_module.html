KYVPTL_API KY_RESULT KYVP_CALLCONV KYVP_CALLCONV KYVPLibTL_InitLib ( void  )

KYVPLibTL_InitLib()

This function must be called prior to any other function call to allow global initialization of the GenTL Producer driver. This function is necessary since automated initialization functionality like within DllMain on MS Windows platforms is very limited
